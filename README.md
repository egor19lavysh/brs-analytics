# БРС.Аналитика

Веб-приложение для просмотра и сравнения рейтинговых данных студентов, групп и направлений. Данные загружаются с сайта рейтинга СПбГЭУ, а результаты анализа отображаются в виде графиков.

## Возможности

- Выбор учебного курса и сравниваемых объектов: студентов, групп или направлений.
- Просмотр рейтинга студента по предметам и семестрам.
- Сравнение баллов и успеваемости с помощью графиков.
- Кэширование загруженных данных в Redis.

## Требования

- Python 3.10 или новее.
- Redis, доступный приложению по адресу `localhost:6379`.

## Установка и запуск

Из корневой папки проекта установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустите Redis, затем приложение:

```bash
python src/app.py
```

Откройте адрес, указанный NiceGUI в консоли (по умолчанию `http://localhost:8080`).

## Структура проекта

- `src/app.py` — веб-интерфейс и получение данных для сравнения.
- `src/parser.py` — загрузка и разбор рейтинговых таблиц.
- `src/dashboard.py` — подготовка данных и логика сравнения.
- `src/visual.py` — построение графиков.
- `src/redis_cache.py` — чтение и запись кэша в Redis.

Кэш хранится в Redis с временем жизни по умолчанию 60 секунд. В нём используются сериализованные Python-объекты, поэтому подключайте приложение только к доверенному экземпляру Redis.
